Descripción: qué prueba el proyecto (login en UI, API y mobile).
Requisitos: Node.js LTS.
Instalación: npm install y npx playwright install.
Ejecución: los comandos del Día 3 (npx playwright test tests/login.spec.js --project=chromium) y del Día 6 (npx playwright test tests/api.spec.js --project=chromium).
Estructura: qué contiene tests/ (los archivos de prueba) y qué contiene pages/ (las clases de página, como LoginPage.js).
